# בונים עתיד | השקעות וצמיחה עם אבישי חניא

אתר סטטי, מתפרסם דרך GitHub Pages.

- `content/` – טקסט הפרקים, בפורמט וואטסאפ (‎*מודגש*‎, ‎_נטוי_‎).
- `build.py` – רשימת הסדרות והפרקים, והמרה ל-HTML. הרצה: `python3 build.py`.
- `posts/`, `index.html` – נוצרים אוטומטית מ-build.py. לא לערוך ידנית.
- `assets/` – עיצוב ולוגו.

להוספת פרק: שומרים את הטקסט ב-`content/<מספר>.txt`, מסמנים `published: True` ב-build.py, ומריצים את הבנייה.
